# Демонстрационные проекты

[English](README.md)

Демо-версия создаёт два вымышленных проекта в новой установке Stream. Подключите
к этому серверу браузер и Handler: в них будут одни и те же записи и файлы.

- **Orbit Studio**: шесть ассетов, секвенция и три шота; этапы model, lookdev и review;
  задачи с исполнителями и датами, заметки и опубликованные картинки. У Survey Drone
  есть вторая публикация lookdev, чтобы можно было посмотреть историю версий.
- **Atlas Reference Library**: три референсных ассета со своими задачами, заметками
  и публикациями. Переключение проекта меняет рабочий контекст.
- **Пользователи**: Maya Chen и Leo Martins могут редактировать записи, Nora Kim —
  читать. Пароли создаются заново для каждой установки и сохраняются в
  `demo-accounts.json` внутри папки данных сервера. Пароль администратора вы задаёте сами.
- **Плагины**: [Studio Review](../studio_review/README.ru.md) добавляет доску ревью
  с примерами записей, Workspace Pulse — дашборд проекта. Это установленные пакеты:
  их скрипты и описания интерфейса можно открыть и изучить.
- **База знаний**: в каждом проекте есть опубликованная вводная статья, связанная с ассетом.

Начните с **Item View**: откройте Survey Drone, его задачи и публикации. Затем
перейдите в задачи/Gantt и страницы плагинов. Войдите как Nora, чтобы сравнить права.
Данные можно менять — это примеры, а не копия рабочей базы студии. Шесть иллюстраций
PNG в `assets` созданы для презентации проекта и распространяются как вымышленные
демонстрационные материалы по лицензии репозитория.

Демо поставляется отдельным набором с контрольными суммами. Установка отказывается
добавлять его поверх существующего рабочего проекта. Повторный запуск после успешной
установки сохраняет ваши изменения и пароли. Если первая установка оборвалась,
сохраните данные и логи для диагностики, а повторите её в новой пустой папке:
инициализатор не удаляет частично созданный проект.

Подготовка набора из исходников:

```sh
cd tactic_stream
python -m tools.demo_delivery --output /path/to/new/demo
python -m tactic_stream --data-dir /path/to/new/data init --demo /path/to/new/demo
```

Демо-пакеты [Windows](../../tactic_stream/docs/delivery/WINDOWS_DELIVERY.ru.md),
[Docker](../../tactic_stream/docs/delivery/SERVER_DELIVERY.ru.md) и
[DSM](../../tactic_stream/docs/delivery/DSM_DELIVERY.ru.md) выполняют этот шаг при
установке. В чистых пакетах демонстрационного набора нет.

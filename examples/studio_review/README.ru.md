# Studio Review

Полноценный штатный плагин для существующего рабочего проекта.

1. Запустите `python TS/examples/studio_review/build.py` из рабочей папки.
2. Администрирование → Плагины → Установить пакет: загрузите
   `TS/releases/studio-review-1.0.0.zip`, проверьте файлы и активируйте в тестовом проекте.
3. Откройте Studio Review в навигации. Колонка статуса/прогресса использует
   `studio_review.column`. Виджет `studio_review.widget` включает её как вложенный
   макет. Предпросмотр доступен в разделе «Состав пакета».
4. Выберите `studio_review.theme`, сохраните изменения и примените тему к проекту.
   Светлый/тёмный режим остаётся личным. Кнопка личного оформления отменяет тему.
5. Выберите **approve**, введите `{"review_code":"STUDIO_REVIEW_001"}`,
   выполните и подтвердите. Действие меняет реальную запись через Search/SObject.
6. Экспортируйте ZIP с изменениями, проверьте перезагрузку и удалите плагин.
   Удаление удаляет собственную таблицу, выбранные настройки и ссылку навигации.

Плагину принадлежат тип `studio/review` и таблица `studio_review`, конфигурации
`studio_review.*`, скрипт `plugins/studio_review/approve`, настройка
`studio_review/installed` и ссылка `studio_review`. Перед адаптацией смените
пространство имён, если эти имена уже используются. Тема не включается автоматически.

Сборщик создаёт обычные SPT и ZIP средствами стандартной библиотеки. Установкой,
транзакциями, DDL, файлами и Python-кодом управляют штатные механизмы TACTIC.
Экспорт менеджера сохраняет изменения установленных ресурсов и данных;
повторный запуск сборщика примера возвращает исходные демонстрационные данные.
Python-код исполняется на сервере с правами доверенного администратора.

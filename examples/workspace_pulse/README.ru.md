# Workspace Pulse 1.0.0

Универсальный пример плагина для ТС и ТХ. Один ZIP можно независимо подключать
к разным проектам. Новые рендереры, сервисы и зависимости не устанавливаются.

В **Администрирование → Плагины** выберите рабочий проект, установите
`workspace-pulse-1.0.0.zip`, просмотрите содержимое и активируйте плагин.
Обновите навигацию проекта. В обычном сайдбаре появятся два пункта:

- **Pulse** — задачи проекта, счётчики наличия сроков, общие фильтры по статусу,
  исполнителю и процессу, графики статусов и исполнителей, таблица задач
  со сроками и штатным поиском с подсказками.
- **VFX overview** — счётчики и таблицы существующих эпизодов, сцен, шотов и
  ассетов. Плагин находит их по реальной схеме проекта, включая типы из шаблонов.
  Если подходящих типов нет, он сообщает об этом и не создаёт лишние сущности.

Имена и коды проектов, названия статусов и пайплайнов не зашиты. Демо-записи,
превью-заглушки и внешние подключения не создаются. Страницы можно менять
штатным редактором и через внутреннего агента с обычными правами.
Нестандартные названия таблиц можно добавить в `workspace.py` перед активацией.

**Удалить из проекта** удаляет только конфигурации плагина и его пункты меню.
Задачи, файлы и остальные данные остаются. Перезагрузка плагина пересоздаёт его
страницы: предварительно экспортируйте свои правки. После добавления новых
VFX-типов перезагрузите плагин, чтобы включить их в обзор.

Сборка ZIP, устройство пакета и ссылки на серверные API описаны в `README.md`.

## Необходимые поправки к первоначальным планам

- Это **Python TACTIC + Vue renderer + конечный JSON API**, а не переписанный на JavaScript backend.
- Фактически нет Vite, TypeScript, PrimeVue, Vue Flow, Pinia, Vue Router в production build. Options API / JavaScript и специальный `build.cjs` с явным списком SFC; GraphEditor — текущая собственная реализация.
- Подключение уже на штатном `/tactic/<project>/`, API `/api/ui/v2`, static `/tactic-ui` в оригинальном CherryPy. Не надо возвращать отдельный demo-server или overlay.
- Состояние UI — исходный `WidgetSettings/sthpw/wdg_settings`, но native JSON имеет отдельные keys; это не полная взаимозаменяемость всех старых настроек.
- `Table`, `CellEdit`, `Edit`, `Tab`, `CustomLayout` — отдельные семантические механизмы. Переименовать их в разные названия generic CRUD недостаточно.
- Вход пока admin-only; наличие редактора Security не означает полной готовности обычных пользовательских ролей.
- Старые UI-пакеты остаются обязательными из-за бизнес-команд и dynamic class paths. Их ещё нельзя удалять.

## Полный список UI и что означают цифры

Свежий статический скан 0.20: **1351 файл-кандидат**, **1497 top-level классов**, **6022 метода**; 2 Python AST parse errors. Из файлов **837 принадлежат известным поставляемым библиотекам** (Ace, CKEditor, MooTools, Bootstrap и font-awesome source support), а не самостоятельным экранам TACTIC.

Поэтому ни 50 Vue SFC, ни число aliases, ни 1351 candidates не дают осмысленного процента миграции. Оставшиеся classes могут быть helpers, commands, унаследованными/динамически вызываемыми виджетами; отсутствие совпадения в registry не доказывает отсутствие работы или ненужность класса.

`inventory/ALL_UI_FILES.md` — построчный список всех кандидатов. `legacy_ui_inventory.json` — каждый класс, методы, места статических ссылок, хеши, candidate status. Все `full_parity_verified=false`: этот handoff не выдаётся за ручную поведенческую сверку 1351 файлов.

`STOCK_SIDEBAR.md` показывает определения штатного sidebar отдельно от готовности его действий. Папка/разделитель — не отсутствующий renderer. Generic config-таблица Triggers не равна полному Triggers editor.

## Граница достоверности

**Сейчас выполнены:** проверка SHA/CRC baseline, сверка 7692 хешей manifest, build metadata, чтение основных кодовых путей, свежий статический индекс и составление handoff.

**Сейчас не выполнялись:** функциональные тесты, сервер, браузер, Windows и PostgreSQL. `evidence` содержит сохранённые свидетельства прошлых выпусков с их собственными caveats. Не переносить их числа в будущий отчёт как заново пройденные.

Три вида утверждений разделены: фактический код 0.20, исторический reported validation, дальнейший план. Незакрытая проверка должна остаться незакрытой.

## Размещение в следующей рабочей копии

Распаковать приложение 0.20 отдельно от данных. Положить содержимое этого пакета в `docs/handoff-0.20/`. Прочитать имеющийся `AGENTS.md`, если он есть, и объединить полезные правила из нашего кандидата. Не менять номер приложения только ради добавления документации.

Сохранить работающие Python и `local_data`; INIT ради передачи не нужен. Сначала создать baseline commit, затем выполнять `05_FIRST_TASK_FOR_CODEX.md`. Все дальнейшие изменения — на отдельной ветке и тестовой копии данных.

# Tactic Frame

Рабочее имя общего каркаса интерфейса TACTIC Handler и TACTIC Stream.
Это прототип: один исходник компоновки и поведения, два нативных рендерера.
Самостоятельный язык и новый парсер здесь не создаются.

`.mjs` обозначает обычный JavaScript-модуль. Наше описание UI — объекты с
именованными полями, которые этот модуль возвращает. Qt и Vue выполняют один
и тот же общий код; рендереры создают контролы соответствующего движка.

## Где что читать

| Файл | Ответственность |
| --- | --- |
| [gantt.json](gantt.json) | Размеры, типографика, исходный размер окна и переводы |
| [gantt.ui.mjs](gantt.ui.mjs) | Общая компоновка: слои, элементы, подписи, цвета и события |
| [gantt.state.mjs](gantt.state.mjs) | Начальное состояние, геометрия, переходы, даты, drag, zoom, Undo/Redo |
| [GanttDemo.qml](GanttDemo.qml) | Нативное отображение объектов сцены через Qt и контролы Handler |
| [GanttDemo.vue](GanttDemo.vue) | Отображение тех же объектов через DOM и App-контролы Stream |
| [gantt_cases.json](gantt_cases.json) | Одинаковые сценарии реального ввода для обеих реализаций |

Начинать чтение с `scene()` в `gantt.ui.mjs`: сверху вниз идут панель действий,
заголовки, шкала дат, группы и строки задач, обзор, прокрутка и нижняя панель.

## Как описан элемент

Реальный фрагмент описания кнопки из цикла панели действий:

```js
add(toolbar, "Button", button.id, {
  x: buttonX,
  y: 6,
  width: buttonWidth,
  height: 36,
  text: translate(button.text),
  action: button.action,
  enabled: button.enabled
});
```

`Button` — имя кирпичика. `id` — стабильный идентификатор. Координаты относительны
к содержащему слою. `action` — данные общего события; в описании нет вызова API
или обработчика, отдельно написанного для QML и Vue.

Слой имеет собственные `x`, `y`, `width`, `height` и список `nodes`. Рендерер
обрезает его содержимое по границам. Внутри слоя элементы рисуются в порядке
описания: фон, сетка, полоса задачи, её заполнение, подпись и управляющие маркеры.
Поэтому части графика действительно накладываются, как в обычной QML-сцене или
DOM. Этот порядок задан один раз для обеих реализаций.

Простая форма в [screen.json](screen.json) использует вложенные `Row`/`Column`.
Гант требует вычислений шкалы и полос; они выражены обычным JavaScript. JSON
не используется для хранения исполняемых выражений или строк кода.

## Где нативные кирпичики

- QML: `D:/code/th_codex/thlib/ui/qml/controls`.
- Vue: `D:/code/TACTIC_VUE/tactic_stream/frontend/src/controls`.

В прототипе узлы `Button` и `CheckBox` используют существующие общие контролы;
`Label` и `Rectangle` отображаются средствами Qt и DOM. Полного каталога
контрактов всех контролов проекта пока нет. Рендереры не заменяют Qt/Vue и
не переводят произвольный QML в HTML.

Общий модуль не обращается к DOM, Qt, сети или файловой системе. Его JavaScript
должен поддерживаться обоими движками. Сохранение и полномочия остаются у
предметных контроллеров и TACTIC; в этом стенде изменения хранятся в памяти.

## Запуск и проверка

`start_demo.cmd` открывает нативный QML и браузерный отчёт с живым Vue.
Отчёт: [output/gantt-report.html](output/gantt-report.html).

Из каталога `tactic_stream`:

```powershell
.venv/Scripts/python.exe -B -X utf8 tools/shared_ui_demo/gantt_qml.py --capture
cd frontend
$env:STREAM_BROWSER_CHANNEL='msedge'
node tests/shared_gantt_demo.mjs
node tests/shared_gantt_report.mjs
```

Проверка сравнивает 160 парных состояний, реальную геометрию, цвета и параметры
шрифтов, общий граф сцены и историю операций. Растеризация текста отличается
между Qt и Chromium. Production-экраны, серверное сохранение, большие списки
и мобильная компоновка в этот прототип не входят.

Обязательные правила развития: [shared_ui_contract.md](../../docs/shared_ui_contract.md).

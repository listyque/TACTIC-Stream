Пункт 6: поиск и карточки результатов

Слева — архив Handler перед B06, в центре — текущий QML, справа — Vue. Архив уже содержит предыдущие этапы Frame; это не исходный Handler до начала всей миграции. Скриншоты проверяют показанные состояния. Поведение запросов, сохранение и права проверяются отдельными сценариями.

Для расширенного поиска, панели страниц, заголовков тегов/быстрых фильтров и действий видимости автоматически сопоставлены геометрия, типографика и цвета общих контролов. Изображения карточек и редактора предназначены для сравнения рядом; совпадение всех пикселей между разными движками шрифта не заявляется.

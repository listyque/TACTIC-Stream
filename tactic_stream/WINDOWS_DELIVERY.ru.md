# Portable-комплект для Windows

Комплект x64 содержит `TACTIC Stream.exe` (Electron), Python 3.14.9,
SQLite, Stream и обычный Handler с закреплённой зависимостью PySide6.
Системные Python, Node.js и исходники не нужны. Распакуйте весь ZIP
в доступную для записи локальную папку; сохраняйте вместе runtime, resources
и лицензии. EXE не подписан. Приёмка на чистой Windows VM ещё предстоит.

Запустите `TACTIC Stream.exe`. При первом запуске штатный установщик откроет
консоль и запросит новый пароль администратора. Готового пароля в комплекте нет.
Затем launcher обновит штатную схему, запустит локальный монитор с воркерами
на loopback и откроет существующий Vue UI. Закрытие окна останавливает его backend.
Занятый порт или ошибка установки не приводят к сбросу существующих данных.
Системные подтверждения используют язык Windows (английский/русский),
язык интерфейса приложения выбирается в Appearance.

По умолчанию данные находятся за пределами папки программы:

- `%APPDATA%\TACTIC Stream\server`: БД, repository, XML-конфигурация и журналы.
- `%APPDATA%\TACTIC Stream\browser`: браузерные сессии и настройки интерфейса.
- `%APPDATA%\TACTIC Stream\handler`: настройки, presets и кэши обычного Handler.

Для отдельной установки: `"TACTIC Stream.exe" --data-dir "D:\Tactic data"`.
Выбранный локальный порт сохраняется в `server/config/tactic-conf.xml`.
Для подключения Handler возьмите его из этого файла или адреса окна Stream.
Запустите `Handler.cmd`, затем настройте обычный server preset, войдите и выберите
проект существующим механизмом Handler. Браузерные сессии ему не передаются.
`TACTIC_HANDLER_SETTINGS_DIR` меняет каталог профиля Handler;
`TACTIC_QML_TEST_SETTINGS_DIR` имеет приоритет для изолированных тестов.
Handler может подключаться к удалённому серверу без запуска локального Stream EXE.
Локальный EXE управляет только собственным локальным backend.

Перед обновлением закройте оба приложения и скопируйте весь каталог данных.
Распакуйте новый комплект в новую папку и запустите с прежним каталогом данных.
Не переносите БД и настройки в папку программы. Штатный upgrade выполняется до
запуска сервера; замена EXE не откатывает БД. Для восстановления сохраните старый
комплект и соответствующую резервную копию данных до обновления.
Миграция legacy-проектов и полная приёмка backup/restore остаются отдельной работой L12.

Сборка из рабочего checkout под Windows x64 с Python 3.14:

```powershell
.venv\Scripts\python.exe -m tools.windows_delivery --handler "D:/grav/Tactic Stream/TH" --output "../releases/windows-0.112.193"
```

Выходная папка не должна существовать. Архивы Python/Electron проверяются
по закреплённым SHA-256; зависимости устанавливаются из wheels во встроенный
runtime. `manifest.json` содержит точные версии и хеши файлов.
Файл `_pth` отключает поиск системных и пользовательских Python-пакетов.
Архив Handler использует существующий разрешённый список исходников
и не содержит сохранённых настроек и учётных данных.

# TACTIC на Windows

Скачайте пакет для Windows x64 из [релизов Stream](https://github.com/listyque/TACTIC-Stream/releases)
или [релизов Handler](https://github.com/listyque/TACTIC-Handler/releases).
Python и нужные библиотеки уже внутри: исходники, установленный Python и Node.js
не требуются. Это предварительные сборки без цифровой подписи.

| Пакет | Состав | С чего начать |
| --- | --- | --- |
| Handler Clean | Нативный Handler, Python и PySide6; подключается к вашему серверу | Запустите Setup EXE, затем TH Setup.exe |
| Handler Demo | Handler, локальный сервер Stream и демо-проекты | Запустите Setup EXE, настройте Stream, затем откройте TH Setup.exe |
| Stream Clean / Demo | Stream EXE, Python, SQLite и браузерный интерфейс | Распакуйте ZIP целиком и запустите TACTIC Stream.exe |
| TH + TS Clean / Demo | Оба приложения в одной переносимой папке | Распакуйте ZIP, запустите Stream, затем TH Setup.exe |

В демо Handler включён сервер: проекты и публикации хранятся на нём. Одни и те же
данные можно открыть в нативном Item View и в браузере. В чистых пакетах нет демо-набора
и рабочих проектов. Сохраняйте runtime, resources и лицензии рядом с приложениями:
одного скопированного EXE недостаточно.

## Первый запуск

**Stream:** откройте `TACTIC Stream.exe`. Консоль дважды попросит новый пароль
администратора. Войдите с логином `admin` и этим паролем. Приложение создаст свою базу,
запустит сервер на loopback и откроет интерфейс. Закрытие окна останавливает локальный
сервер; оставляйте его работающим, пока подключённый к нему Handler нужен в работе.

**Handler:** откройте `TH Setup.exe`. Укажите адрес сервера, войдите, выберите проект
и репозиторий, примените настройки. Затем запустите `TACTIC Handler.exe`.
Мастер также настраивает поддерживаемые DCC-плагины и шелф. Для удалённого сервера
укажите его URL — локальный Stream запускать не нужно.
`TH Setup Builder.exe` позволяет собрать установщик с общими настройками развёртывания.
Пароли и токены сессий в такие настройки не входят.

**Демо:** первый запуск Stream создаст Orbit Studio и Atlas Reference Library,
картинки, публикации, задачи, пользователей, workflow и примеры плагинов.
Подробнее — в [знакомстве с демо](https://github.com/listyque/TACTIC-Stream/wiki/Demo-ru).
Начальный адрес сервера: `http://127.0.0.1:18881`. Пароли созданных пользователей —
в `%APPDATA%\TACTIC Stream Demo\server\demo-accounts.json`.
Демо не устанавливается поверх рабочих проектов и не сбрасывает уже установленный набор.

## Где хранятся данные

- Stream Clean и чистый комплект TH + TS: `%APPDATA%\TACTIC Stream`.
- Все локальные демо-комплекты: `%APPDATA%\TACTIC Stream Demo`.
- Внутри: `server` — базы, опубликованные файлы, конфигурация и логи;
  `browser` — браузерные сессии; `handler` — профиль комплектного Handler.
- Отдельный Handler Clean хранит профиль в своей папке `TACTIC-Handler`.
  Устанавливайте его в доступную для записи папку, а не в защищённый системный каталог.

Чистая версия и демо могут работать рядом. Три демо-комплекта используют один
демо-профиль по умолчанию: это разные способы открыть один локальный сервер.
Для отдельного экземпляра Stream запустите `"TACTIC Stream.exe" --data-dir "D:\Tactic data"`.
Порт записан в `server/config/tactic-conf.xml`; чистая версия при первом запуске
выбирает свободный. Для отдельного профиля Handler задайте `TACTIC_HANDLER_SETTINGS_DIR`.
В изолированных тестах приоритет имеет `TACTIC_QML_TEST_SETTINGS_DIR`.

## Обновление и восстановление

Закройте оба приложения и сохраните полную копию папки данных и профиля.
Новый ZIP распакуйте отдельно и используйте прежнюю папку данных Stream.
Штатное обновление схемы выполняется до запуска сервера. EXE-установщик Handler
сохраняет локальные настройки и репозиторий, оставляет папку предыдущей установки
и отказывается перезаписывать изменённые файлы приложения.

Сохраните старое приложение и соответствующую ему копию данных до обновления.
Замена EXE не откатывает схему базы. См. [порядок восстановления](RECOVERY_ACCEPTANCE.md).
Проверки конкретной сборки перечислены в её релизе; результаты старой приёмки
не подтверждают готовность нового пакета. File Workspace остаётся прототипом.

## Сборка

Из `tactic_stream`, с Python 3.14 на Windows x64:

```powershell
.venv/Scripts/python.exe -m tools.windows_delivery --handler ../../TH --edition suite --demo --output ../releases/TACTIC-Suite-Demo
```

Варианты `--edition`: `handler`, `stream`, `suite`. Без `--demo` получится чистый пакет.
Выходная папка не должна существовать. Сборщик проверяет закреплённые архивы Python/Electron,
устанавливает wheel-пакеты в изолированный runtime и компилирует существующие .NET-лаунчеры
Handler. Для Handler также создаётся самостоятельный Setup EXE.
`manifest.json`, `BUILD.json` и `SHA256SUMS` содержат версии и контрольные суммы файлов.
Встроенный Python не использует системные и пользовательские пакеты. В архив Handler
не попадают сохранённые пароли, настройки и частные скрипты.

# Параметры Check-in

Штатный `versionless_mode` задаётся отдельно: в настройках проекта `config/prod_setting`
или серверном разделе `checkin`. Проектное значение имеет приоритет. `copy` создаёт копию,
`hardlink` использует тот же файл на одном томе, `symlink` требует разрешения ОС.
Windows `WinError 1314` при обновлении latest означает отсутствие права на символическую
ссылку; для репозитория на одном томе можно явно выбрать `hardlink`. Это распространяется
и на вложения заметок. Новые чекины используют выбранный режим; существующие файлы не мигрируют.

> Defaults задают начальное состояние новых поисков и заданий браузерного чекина. Сохранённые виды поиска и уже подготовленные задания очереди сохраняют свои явные параметры.

| Параметр | Действие |
| --- | --- |
| Лимит результатов | Размер новой страницы поиска, целое 1–500; default 20. |
| Режим загрузки | Страницы или бесконечная прокрутка. |
| Вид по умолчанию | Непрерывное дерево; доступны карточки/таблица/компактные строки/версии справа и снизу. |
| Группировать файлы | Один снапшот для выбранных файлов или отдельный для каждого. |
| Сохранять имя | Исходные имена вместо штатного naming-шаблона. |
| Создавать превью | Передавать create_icon в штатный чекин; при отключении веб-превью/иконки не генерируются. |
| Подтверждать ревизию | Начинать замену ревизии с требованием явного подтверждения. |
| Очищать завершённые | После пакета удалять успешные Complete; оставлять Failed/Result unknown для проверки. |

Данные идут из `preferences.checkin` в searchTab/ObjectCheckin/CommitQueue, затем в штатные simple_checkin или UploadedCheckinCmd/FileCheckin/IconCreator. Коллизии версий, ревизии, rollback, права и versionless остаются штатными. Перенос/копирование локальных файлов, запуск связанных приложений и сканирование папок требуют настольного клиента.

«Репозитории» → Repository Editor задаёт доступные места назначения и Default новых чекинов браузера. В форме есть явный выбор репозитория. Выбранный алиас передаётся через UploadedCheckinCmd в штатный FileCheckin даже для одного файла; без явного алиаса сохраняется прежний путь simple_checkin. Ревизия остаётся в репозитории своего снапшота. Description → Pin заполняет начальное описание новых форм; подготовленные операции сохраняют свой текст.

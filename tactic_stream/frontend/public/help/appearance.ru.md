# Настройка внешнего вида

> Здесь настраиваются тема, набор семантических иконок, анимации, язык интерфейса и предпочтения
> браузера. Изменения видны сразу; применение/сохранение записывает их.

## Внешний вид

| Параметр | Что меняет |
| --- | --- |
| **Тёмный режим** | Использует тёмные поверхности и тёмную палитру выбранного стиля. При отключении используется светлая палитра. |
| **Стиль интерфейса** | Выбирает правила оформления компонентов. Каждый стиль отдельно запоминает светлую и тёмную палитры. |
| **Палитра светлого режима** | Базовый цвет поверхностей и акцент при выключенном тёмном режиме. |
| **Палитра тёмного режима** | Базовый цвет поверхностей и акцент при включённом тёмном режиме. |
| **Набор иконок** | Выбирает встроенный шрифт семантических иконок. По умолчанию используется Material Design Icons. Автоматический режим использует предпочтительный набор приложения, остальные варианты явно фиксируют семейство. Глифы Material Design и Fluent оптически увеличиваются до размера Font Awesome без изменения геометрии кнопок. Неизвестные динамические иконки по-прежнему берутся из другого встроенного семейства, а не исчезают. |
| **Анимации нажатия** | Анимирует отклик на клик, рябь, переключатели и раскрывающиеся элементы. Без анимации состояние всё равно меняется. |
| **Анимации наведения** | Анимирует переход при наведении указателя. При отключении состояние наведения появляется мгновенно. |
| **Плавные переходы** | Анимирует появление содержимого, смену видов, раскрытие и другие переходы. |
| **Анимации меню и окон** | Анимирует меню, выпадающие списки, попапы и подсказки. Отключите для мгновенного открытия и закрытия. |

Включённые анимации во всех стилях теперь примерно в 2,5 раза короче прежних. Переключатели выше по-прежнему полностью отключают соответствующие анимации.

## Язык

**Язык интерфейса** меняет подписи приложения и выбирает справку на том же языке. Названия проектов,
Search Type, процессов, статусов и другие серверные данные никогда не переводятся.

Общие сообщения интерфейса используют те же переводы исходного текста, что и текущий TACTIC Handler. Подписи обновляются в открытом окне без потери черновика; при отсутствии перевода показывается английский исходный текст. Специальные сообщения Stream и Markdown-статьи справки используют собственные языковые ресурсы.

## Настройки браузера и предпросмотр

Системный цветовой режим, отдельные заметки и предпросмотр иконок остаются видимыми дополнениями. Палитры используют общий контрол 36px с кругом акцента 18px. Тема, анимации и язык сразу видны в открытой конфигурации; применение/сохранение записывает их, отмена восстанавливает последнее применённое состояние. Системное reduced-motion имеет приоритет. Выбор графического движка относится к Qt; веб-отрисовкой управляет браузер.

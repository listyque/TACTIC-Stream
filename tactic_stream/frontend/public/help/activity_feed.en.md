# Activity Feed

> A read-only journal of notes, publications, tasks, status changes, object changes and work hours in the current project.

**My objects** shows your actions. Choose users or exclude your own activity to narrow the journal.
Search filters loaded events; older events load automatically while scrolling. The calendar counts all accessible history, including events not loaded in the list. Choose a day to see its events.

Links open the related object or task. Activity notifications have their own switch and open the feed when selected. The journal is separate from [Messages](communication.en.md) and runtime System Activity.

**Help** opens the shared catalog. Closing it returns to the feed with the same filters and position.

## Filters, calendar and notifications

User and calendar filters are anchored panels. Pending selections are prepared
before opening, so the first click is retained. The calendar keeps the month you
are viewing while day counts arrive. The list, event cards and expanded change
values resize with the window; scrolling keeps space for the scrollbar.

Notifications opens the session history with All, Server, Check-in and Client
filters. Handler additionally shows Repository Sync. Clearing history does not
change the activity journal or messages. Message and activity notices open their
source; quick reply retains its text when sending fails. Phone error notices keep
long diagnostic text in a scrollable area instead of covering the whole screen.

On a phone the search row stays compact. Activity options expands the filters; collapsing it keeps their values and gives space back to the event list.

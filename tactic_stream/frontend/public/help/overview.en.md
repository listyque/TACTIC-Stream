# Overview

> TACTIC Stream is the browser workspace for project objects, files, tasks and team communication. It uses the same headless TACTIC business logic as existing clients.

## Main controls

Select a project in the top bar, then open a Search Type or saved search from the navigation drawer. The drawer opens above the workspace. The compact rail selects an open section; each section has its own Search tabs.

The main search field is the starting point for finding objects. Filters, tags, sorting and grouping refine the active tab. Additional operations are in compact menus; the footer controls pages, continuous loading and object creation.

## Work with an object

1. Find and select an object in the active project.
2. Expand its processes and schema-declared child relations.
3. Open its tasks, notes, files or editor through the item actions.
4. Review the prepared operation, then save or apply it explicitly.
5. If a request fails, read the error and Debug Log before retrying a write.

## Windows and communication

Configuration and Administration open separately from project navigation. Functional dialogs share a title bar: drag to move, double-click or use the maximize button to expand, then restore the previous geometry. Small screens use the available viewport.

Messages contains direct and group conversations. Activity Feed shows project audit events; System Activity shows runtime operations. These are separate surfaces.

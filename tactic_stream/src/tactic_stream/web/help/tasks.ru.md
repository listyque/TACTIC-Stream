# Задачи и планирование

> Инструменты задач предоставляют редактирование задач объекта и проектные представления: таблицу,
> диаграмму Ганта, календарь, табель и отчёты.

## Основные элементы

Нажмите редактируемую ячейку задачи один раз, чтобы сразу открыть выбор пользователя или статуса. Прогресс меняется ползунком с отображением процента. Плановые часы — кнопками увеличения и уменьшения с шагом 15 минут и видимой единицей измерения; значения проекта в минутах пересчитываются автоматически. Начало и срок остаются в общем редакторе из двух полей. Изменения ячеек сохраняются в черновике до команды «Сохранить изменения задач».

Используйте область задач, фильтры команд, быстрые фильтры, колонки, сортировку, группировку,
массовое выделение, редакторы статуса и исполнителя, даты, прогресс, заметки и удаление. Значок
задач на sObject или процессе открывает менеджер задач в области «Выбранное».
При переходе по бейджу объекта или процесса фильтры прежней области сбрасываются;
бейдж процесса затем применяет только фильтр этого процесса. Активные фильтры подсвечивают
кнопку фильтра зелёным (на узкой ширине — кнопку дополнительного меню). Если фильтры
скрыли все задачи, пустое состояние предлагает очистить их, а не создавать задачу.

Выбор строки задачи обновляет инспектор для этой задачи, не меняя сохранённое развёрнутое или
свёрнутое состояние инспектора. Если у одного процесса несколько задач, меню бейджа показывает
контекст, исполнителя и статус каждой задачи; строка процесса открывает список задач из уже
загруженных данных.
При переключении вкладок поиска с тем же объектом и процессом инспектор сохраняет загруженные
задачу и заметки; при выборе другого контекста обновляет их.

Процесс воркфлоу типа **progress** остаётся в меню Инспектора задач. Он помечен тем же значком и
счётчиком «одобрено / всего», что и бейдж прогресса на объекте. При выборе показываются задачи
объектов, связанных через схему проекта, а область выбранных объектов в Менеджере задач
переключается на эти объекты. Задача на родительском объекте не создаётся и не
редактируется. Загружать снапшоты в такой процесс нельзя. Если для указанного в воркфлоу
серч-тайпа нет связи в схеме, инспектор сообщает об этом, а не подбирает объекты по догадке.

## Как пользоваться

- Только область «Выбранное» следует за выделением sObject; области проекта, Search Type,
  пользователя и команды не меняются, а компактные редакторы задач продолжают следовать за выбранным
  результатом.
- Значки заметок используют нативные счётчики TACTIC по процессам.
- «Редактировать sObject» открывает редактор на основе серверной схемы и всегда загружает явно
  запрошенный объект, даже если окно уже открыто.
- Удаление открывает общий редактор зависимостей, где перед удалением можно проверить заданные
  TACTIC зависимости и галки по умолчанию.
- При удалении задачи заметки того же родительского sObject и процесса показываются отдельной
  отмеченной группой зависимостей; снимите галку, чтобы сохранить их.
- Ссылки на задачи из ленты активности, сведений об объекте и профилей пользователей принимают оба
  нативных формата search key TACTIC.
- Обновление области «Выбранное» без sObject сохраняет обычное пустое состояние и не отправляет
  запрос на сервер.
- Область «Выбранное» следует за активной вкладкой поиска и выделенными в ней объектами, включая
  множественное выделение.
- Действие «Все» для типа поиска использует тип этой вкладки, даже если список результатов пуст.
- Скрытые представления задач учитывают актуальный выбор при повторном открытии; несохранённые
  правки задач сохраняются.
- Группы задач по Search Type показывают настроенное название, сохраняя серверный код как стабильный
  идентификатор.
- Фильтрация и сортировка задач выполняются на сервере до разбивки на страницы. После догрузки
  страницы объединяются по стабильному ключу группы без повторных заголовков.
- Быстрые фильтры показывают каждый процесс, статус и другое значение один раз со счётчиком задач
  в текущей области.
- «Загрузить ещё» получает следующую страницу результатов; несохранённые изменения задач остаются
  доступны при смене фильтра.
- Редакторы при наведении создаются только при необходимости. Подсветка строки задачи появляется сразу, а содержимое статуса и исполнителя не сдвигается при появлении редактора.
- Пустой статус одинаково показывается как «Без статуса» в строке и редакторе при наведении; названия статусов из проекта не переводятся.
- После нажатия редактор статуса или пользователя остаётся активным, пока открывается его меню,
  поэтому указатель можно сразу переместить в меню.
- Щёлкните правой кнопкой по заголовку колонки для сортировки, группировки и управления видимостью.
  Любой пользователь может открыть личные настройки колонок в разделе «Конфигурация → Задачи»
  командой «Настроить колонки».
- Кнопка справа в заголовке таблицы выбирает видимые колонки задач; когда заголовка нет,
  например в диаграмме Ганта, то же действие остаётся в дополнительном меню.
- Черновое расписание Ганта остаётся в разделе «Задачи без расписания» до успешного сохранения.
- В диаграмме Ганта потяните за выступающее ушко слева или справа, чтобы изменить даты задачи; полосатая ручка внутри полосы меняет завершённость.
- Пустой менеджер задач сохраняет футер и показывает по центру подсказку создания со стрелкой к
  кнопке +.
- При изменении ширины дока стрелка остаётся привязана к кнопке создания.
- Таблица создаётся асинхронно только при наличии задач в активной области; диаграмма Ганта
  создаётся при первом запросе и сохраняется для плавного переключения.
- Индикатор загрузки остаётся до готовности первой таблицы менеджера задач и её видимых строк;
  быстрые задачи тоже раскладываются до показа, чтобы строки не появлялись каскадом.
- Списки выбора пользователей объединяют разрешённые для задачи варианты с общими данными профилей,
  согласованно отображают группы и результаты поиска и сохраняют исходный вариант при фильтрации.
- Список пользователей подготавливается уже при нажатии на селектор, поэтому его отдельное
  всплывающее окно не открывается с пустым первым кадром.
- Хедер менеджера задач удерживает переключатель представления, меню дополнительных действий и
  обновление у правого края, а второстепенные действия на узкой ширине переносит в это меню.
- После перезапуска менеджер задач отдельно для каждого проекта восстанавливает последний охват,
  фильтры, свёрнутые группы, положение календаря и выбранную задачу.
- Сброс фильтров также закрывает область конкретного пользователя, открытую по бейджу профиля,
  и возвращает «Выбрано». Области, которые можно выбрать вручную, включая «Мои задачи», остаются.
- Отмеченные строки и несохранённые правки намеренно очищаются.
- Поиск задач остаётся видимым в узкой компоновке.
- Компактная кнопка области остаётся рядом с созданием задачи и не занимает гибкое пространство
  строки поиска; на минимальной ширине выбор области доступен из меню дополнительных действий.

## Собственные журналы (0.112.21)

Правки полей задач и собственных заметок можно отменять и повторять через сохранённые
журналы транзакций пользователя. ID заметок и связи ответов сохраняются; удаляйте ответы
раньше родителя. Текущие права parent/type/record/column проверяются заново. Смена статуса
с Workflow/историей пока не поддерживает replay. Проверенный объём и ограничения описаны
в Help: «Внутренняя структура», «Запись задач/заметок и undo/redo».

## Replay статусов/Workflow (0.112.22)

Собственные журналы статусов задач и Workflow одного проекта теперь поддерживают undo/redo
вместе с историей статусов, состояниями процессов, сообщениями/packages и своими заметками.
Текущие права проверяются заново, ошибки откатываются. Исторические Workflow-журналы без
backups сообщений отклоняются. Границы описаны в Help: «Внутренняя структура»,
«Статусы задач и полный Workflow replay».

## Workflow между проектами (0.112.23)

Собственные полные журналы зависимостей теперь проигрываются между проектными БД вместе
со статусами задач, своими заметками, состояниями процессов, историей и сообщениями.
Проверяются текущие права в фактическом проекте каждого исходного родителя; ID и результаты
callbacks сохраняются без их повторного запуска. Проверки и границы — в Help:
«Внутренняя структура», «Replay Workflow между проектами».

## Replay владельца старого состояния (0.112.24)

Собственные полные Workflow-журналы теперь отменяют и повторяют штатное назначение pipeline
старому состоянию с пустым pipeline_code, сохраняя исходный ID и данные. Записанный владелец
должен быть видимым основным pipeline родителя с видимым процессом. Произвольная смена
владельца запрещена. Подробности — в Help: «Внутренняя структура», «Replay назначения
pipeline старому состоянию».

## Гант и календарный док

Таблица и Гант — представления Менеджера задач. Календарь открывает отдельный док «Календарь задач»
кнопкой календаря или через Панели рабочего пространства → Задачи и отчёты. Общие действия доков
позволяют перемещать, стыковать, складывать во вкладки и закрывать его; геометрия и видимость
сохраняются в раскладках. Календарь и Менеджер задач используют общую область, загруженные задачи,
выбранный день и черновики. Выбор дня применяет серверный фильтр, очистка возвращает полный
результат области. На телефоне выберите Календарь задач или Менеджер задач в списке активной панели.
Кнопка списка событий сохраняет доступное в Stream представление задач списком.

В Ганте подписи задач остаются на месте при прокрутке шкалы времени. Колесо над шапкой меняет
масштаб вокруг указателя, Shift+колесо прокручивает время. Для перемещения можно тянуть пустую
шкалу или ползунок обзора. Дни, Недели, Месяцы, Кварталы и Весь период доступны в параметрах
расписания. Кнопка сегодняшнего дня возвращает текущую дату. Сводки групп, выходные, вехи
и предупреждения используют ту же проекцию задач.

Перетаскивание полосы переносит задачу, крайние ручки меняют начало/срок, ручка прогресса —
процент выполнения. Пустое место строки без расписания задаёт даты. Escape отменяет жест;
Отменить/Повторить и Ctrl+Z/Ctrl+Shift+Z работают с общим черновиком. Отмеченные задачи можно
переносить вместе и планировать пакетно. Изменение дат сохраняет исходное время. До сохранения
черновик остаётся в исходной секции расписания. Видимая кнопка редактирования позволяет менять
те же поля без перетаскивания, в том числе на тачскрине. Сохранить/Отменить изменения остаются
в полосе черновиков Менеджера задач. Выбор строки и двойной клик по объекту не сохраняют правки.
Права и исходные ревизии проверяются при подготовке и сохранении; календарь использует общие данные.


## Мобильный Менеджер задач

Проектная таблица задач превращается в карточки: объект, процесс/контекст, статус,
исполнитель, срок и прогресс. Тап или свайп влево открывает отдельный экран полей задачи.
Кнопка «Назад», свайп вправо и Back/Forward браузера возвращают список с прежней прокруткой;
несохранённые изменения остаются в общем черновике. «Сохранить» применяет подготовленный
штатный план, «Отменить» убирает правки. Заметки открываются своей кнопкой после сохранения
или отмены правок этой задачи. Чекбоксы выделяют задачи для массовых действий, группы
сворачиваются тапом. При прокрутке списка вниз строка поиска скрывается, вверх — возвращается.
Gantt остаётся настольным видом, Календарь задач — отдельной мобильной панелью;
настольный вид и черновики сохраняются при смене ширины. Быстрые карточки/список процессов
доступны в параметрах вида задач и перестраиваются в одну колонку.


Область прокрутки Ганта остаётся стабильной при дробных размерах дока и масштабе экрана 125% или 150%. Пустому списку с помещающимся диапазоном дат не нужны полосы прокрутки холста; длинный список и широкий диапазон прокручиваются как обычно. При изменении размеров полосы не должны бесконечно появляться и исчезать.

## Задачи проекта без выделения объекта

В полном Менеджере задач кнопка + работает и без выделенного объекта. Она создаёт задачу только для текущего проекта: asset, shot или другой рабочий объект не нужен. Используется стандартный воркфлоу статусов задач; первоначальный исполнитель — текущий пользователь, поэтому задача попадает в «Мои задачи». Отредактируйте и сохраните её обычными средствами, затем открывайте Инспектор задач. В файловом проекте типа Perforce выбирайте её в разделе связи задач с changelist при submit. Если объект выделен, + по-прежнему создаёт задачу этого объекта.

## Общие контролы Task Manager

Таблица, карточки и компактные строки Quick Tasks, выбор области и фильтров,
список колонок, поля задачи и панель выделения используют общие описания Tactic
Frame. Каждый продукт поставляет отдельную копию и собственные нативные контролы.
Отдельное управленческое окно Handler сохраняет сводку области, нагрузку,
распределение статусов и быстрые пресеты. В Stream остаются мобильный список,
карточка с возвратом и дополнительные команды инспектора и табеля времени.

**Создать задачу** добавляет раскрытую виртуальную строку. Выберите процесс,
контекст и заполните поля: запись попадёт в TACTIC только после **Сохранить**.
**Отменить изменения** удаляет несохранённую строку. Статус, исполнитель,
руководитель и даты используют штатные пикеры. Нажатие на ячейку даты, прогресса
или часов открывает редактор рядом с ней. Число часов подтверждается Enter или
переходом в другое поле и становится изменением строки. Сохраняется настройка
пересчёта часов и минут исходного поля.

Выделяйте задачи чекбоксами. Панель выделения предлагает статус и исполнителя;
**Другие поля** открывает остальные поля. Галочками включаются только поля,
которые нужно заменить. **Применить** на панели выполняет проверенную массовую
операцию. **В черновик** в дополнительных полях подготавливает изменения строк
для проверки и обычной панели сохранения/отмены; **Готово** закрывает редактор.
Для смешанных значений необходимо явно выбрать замену. Изменения сохраняют
исходные ревизии задач. После конфликта или неизвестного результата записи
нужно пройти штатное обновление/согласование перед повторным сохранением.

Перед сменой области, команды, пользователя или размера страницы сохраните либо
отмените изменения. Выбор Teams не меняет область до выбора конкретной команды;
если команд нет, показывается объяснение. Тихое обновление не заменяет открытый
редактор или включённые поля массового изменения. Видимость, ширина и порядок
колонок, сортировка, группировка и размер страницы используют прежние настройки
рабочей области. Колонка объекта обязательна. Гант и отдельный календарь
сохраняются; перенос их планирования относится к следующему блоку.

Права остаются у действующих исполнителей команд. Текущий API рабочей области
задач Stream требует администратора; перенос UI не выдаёт пользователям Handler
дополнительные права сервера и не меняет действующую проверку доступа к задачам.

# Activity Feed

> A read-only journal of notes, publications, tasks, status changes, object changes and work hours in the current project.

**My objects** shows your actions. Choose users or exclude your own activity to narrow the journal.
Search filters loaded events; older events load automatically while scrolling. The calendar counts all accessible history, including events not loaded in the list. Choose a day to see its events.

Links open the related object or task. Activity notifications have their own switch and open the feed when selected. The journal is separate from [Messages](communication.en.md) and runtime System Activity.

**Help** opens the shared catalog. Closing it returns to the feed with the same filters and position.

# Редактор скриптов

> Редактор скриптов хранит и запускает скрипты с подсветкой синтаксиса, нумерацией строк, поиском и
> заменой, подсветкой совпадений, автодополнением, полосами прокрутки, выводом и серверными папками
> скриптов.

Администраторы и супервайзеры могут изменять, сохранять, удалять и запускать код в редакторе.
Остальные пользователи могут просматривать и копировать скрипты, но не изменять, сохранять или
запускать код из редактора.

## Права сервера TACTIC Stream

С 0.112.13 обычный пользователь API/Workflow может запускать доверенный серверный
Python с явным проектным grant `api_cmd` для `tactic.command.PythonCmd`.
Права редактирования скриптов и UI Script Editor не изменены.
С 0.112.14 межпроектный callback Workflow ищет скрипт и проверяет grant в
фактическом проекте своего объекта, затем возвращает проект вызывающей команды.
Это не песочница;
XML правил, проверки, откат и ограничения описаны в [модели ядра](core_model.ru.md).

## Основные элементы

Редактор исходника поддерживает ключевые слова и встроенные объекты Python, имена из текущего
скрипта и API TACTIC Handler gf и tc. Открытые скрипты используют общие вкладки рабочего
пространства.

Дерево скриптов скрывается направленной стрелкой; Local Python и Server Python используют один
Python-глиф разных цветов. Несохранённый исходник новых и серверных вкладок локально
восстанавливается для текущего проекта.
Поиск в дереве остаётся сверху, даже если в текущем проекте нет скриптов.

Local Python выполняется в GUI-потоке Qt, поэтому доверенные скрипты могут напрямую импортировать
или перезагружать нативные UI-модули PySide6 и показывать их окна.

## Как пользоваться

- Панель Source предоставляет историю отмены и возврата на 120 шагов, список истории, вырезание,
  копирование, вставку, размеры текста, поиск, выполнение выделения и справку.
- Вывод доступен только для чтения, но поддерживает текстовый курсор, выделение, копирование,
  сворачивание, горизонтальную прокрутку и автоматический перенос строк.
- Щёлкните серверный скрипт в дереве правой кнопкой, чтобы скопировать runner или удалить его из
  TACTIC.
- Запускайте только доверенные скрипты.
- Copy Script Runner создаёт исходный вызов execute_custom_script для серверного пользовательского
  скрипта.
- Явный путь к локальному Python-файлу может использовать тот же API без обновления или публикации
  скрипта в TACTIC.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Ctrl+S | Сохранить текущий скрипт |
| F5 | Запустить весь скрипт |
| Ctrl+Enter | Запустить выделение или весь скрипт, если ничего не выделено |
| Ctrl+Z / Ctrl+Y | Отменить или вернуть правку |
| Ctrl+X / Ctrl+C / Ctrl+V | Вырезать, копировать или вставить |
| Ctrl+F | Открыть поиск |
| Ctrl+H | Открыть поиск и замену |
| F3 / Shift+F3 | Перейти к следующему или предыдущему совпадению |
| Ctrl+Space | Показать подсказки кода |
| Ctrl+/ | Переключить комментарии для выделенных строк |
| Tab / Shift+Tab | Добавить или убрать отступ у выделенных строк |
| Ctrl+D | Дублировать выделение или текущую строку |
| Esc | Закрыть подсказки или поиск |

## Идентичность и хранение на сервере

Папка и Имя — отдельные поля, вместе образующие проектный путь в дереве. Сохранение записывает
серверный скрипт через TACTIC; Обновить скачивает опубликованное дерево и согласует вкладки, не
уничтожая несохранённый локальный черновик. Маркер изменения означает отличие от последней версии.

Кнопка истории показывает сохранённые редакции активного скрипта. При закрытии одной изменённой
вкладки или всех вкладок можно сохранить, отбросить правки или вернуться к редактору.

## Место исполнения

| Цель | Поведение |
| --- | --- |
| **Самостоятельный Handler** | Запускает поддерживаемый Python в Handler для UI и публичного API. |
| **Выбранный DCC** | Отправляет проверенное действие точному client ID и исполняет скрипт в нативном потоке. |
| **Сервер** | Исполняет поддерживаемый серверный Python через TACTIC и возвращает вывод или traceback. |

В цели по возможности показаны приложение, сцена и PID. Если у клиента нет
`execute_custom_script`, DCC-запуск выключен и не перенаправляется другому клиенту.

Локальный Python — доверенный режим разработчика и намеренно работает в Qt UI-потоке Handler. Не
выполняйте там блокирующие запросы TACTIC, репозитория или тяжёлую файловую работу. DCC Python следует
правилам потока самого DCC; серверную работу отправляйте Handler, не ожидая её в нативном UI-потоке.

## Вывод и отладка

У каждой вкладки свой вывод. stdout, stderr, детали завершения и traceback появляются в сплиттере
Вывода того скрипта, который их создал. Вывод триггера по возможности добавляется во вкладку скрипта.
Панель сворачивается, растягивается, переносит строки, выделяет, копирует и очищает без изменения кода.

Уведомление о завершении — только сводка. Реальные print и traceback смотрите в Выводе, а request ID,
runtime-команды и удалённые детали — в Журнале отладки.

## Серверный JavaScript

С 0.112.39 редактор поддерживает `server_js`, а Script Shelf запускает его через исходный JsCmd. Выберите **Серверный JavaScript** в Script Editor. Это синхронный код администратора с `server` и глобальными kwargs; браузерный `javascript` сохраняет отдельное окружение. Примеры, транзакции и ограничения — в [Исходном HTML API и серверном JavaScript](html_api.ru.md).

## Выполнение и редактирование в TACTIC Stream

Браузерный JavaScript получает `context`, `project`, `searchType`, `searchKeys`, `rpc(method, args, kwargs)` и `refresh()`. RPC использует вашу учётную запись и захваченный проект. Запускайте только доверенный код: браузерный JavaScript имеет доступ к странице и сессии. Серверный Python использует API TACTIC; вывод print остаётся в серверном журнале. Серверный JavaScript выполняется в QuickJS-NG с `server` и kwargs в глобальной области, без доступа к браузеру и DCC.

Сохранённая ревизия восстанавливается в локальный черновик; Сохранить публикует его. Обновление сохраняет несохранённые черновики. Ctrl+Shift+O открывает структуру; Alt+Up/Down переходит между символами; F12 — к определению; Ctrl+Shift+K удаляет строку. Отмена и повтор сохраняют 120 шагов. Tab или пробел принимает дополнение; Enter вставляет новую строку.

Локальный Python, выполнение в DCC и хуки действий Handler/DCC исключены из веб-редактора. Импортированные скрипты на других языках доступны для чтения. Справка редактора и панели исходного кода открывает эту статью в общем каталоге.

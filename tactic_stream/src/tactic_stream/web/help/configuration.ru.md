# Конфигурация

> В конфигурации восемь страниц по текущему QML ТХ. У каждой независимый черновик: переход между страницами не сохраняет и не отменяет правки.

| Действие | Результат |
| --- | --- |
| Сбросить | Вернуть сохранённые значения текущей страницы, сохранив черновики остальных. |
| Применить | Проверить и сохранить текущую страницу. Окно остаётся открытым. |
| Сохранить | Проверить и сохранить все страницы. Окно остаётся открытым; после сохранения кнопка неактивна. |
| Закрыть | Закрыть чистое окно. При наличии правок предложить сохранить и закрыть, отбросить изменения или продолжить редактирование. |
| Справка | Открыть статью текущей страницы. |

Изменения оформления видны сразу. Отбрасывание изменений восстанавливает последнее применённое оформление, палитры, иконки, язык и анимации. Остальные предпочтения действуют после применения/сохранения. При ошибке хранилища черновик остаётся доступным и показывается ошибка. Если при сохранении всех страниц одна из последующих не прошла проверку, уже применённые страницы остаются сохранёнными: общей транзакции между страницами нет.

На компьютере окно сохраняет скруглённые углы при разворачивании и восстановлении. Кнопка «Закрыть»,
управление рамкой и защита несохранённых изменений остаются доступны при переходе между страницами.
На телефоне сохраняется полноэкранная компоновка.

## Страницы и владельцы данных

| Страница | Что управляет данными |
| --- | --- |
| [Сервер](help://server_configuration) | Адрес и пользователь текущего браузера, интервалы запросов, штатный XML сервера. |
| [Репозитории](help://repository_configuration) | Алиасы из Config/Environment, отдельный редактор и проверка путей на сервере. |
| [Проекты](help://configuration.projects) | Штатный каталог, активация, редактирование, создание и экспорт шаблона. |
| [Параметры Check-in](help://configuration.checkin) | Новые вкладки поиска и новые задания браузерного чекина. |
| [Общие](help://configuration.global) | Уведомления и диагностика браузера. |
| [Внешний вид](help://appearance) | Общая тема/контролы, предпросмотр и видимые дополнения браузера. |
| [Кэш](help://configuration.cache) | Сохранённое раскрытие веток и обновление данных сеанса. |
| [Задачи](help://configuration.tasks) | Начальное состояние Task Manager/Inspector и штатное планирование задач. |

Настройки браузера относятся к его профилю. `tactic_stream.preferences` хранит defaults чекина, задач, уведомлений и кэша. Оформление, сеть и диагностика сохраняют отдельные ключи. Состояние рабочего пространства пользователя/проекта важнее defaults. Записи сервера и тикеты в эти предпочтения не копируются. XML сервера общий для установки и всех клиентов; отметка «Требуется перезапуск» означает перезапуск backend. Активация проекта действует сразу, без ожидания «Применить».

Структура взята из `ConfigurationView.qml`, `Configuration*Page.qml` и `configuration.py`. В Stream её собирают `Configuration.vue`, `ServerConfiguration.vue`, `PreferenceSettings.vue` и существующие владельцы функций. Трей, DCC, движок Qt, пресеты подключения и дисковые кэши не выдаются за работающие настройки браузера. Repository Sync и S3 исключены.

## Проверка

Приватные SQLite/native Command и настоящий Chromium проверяют применение/сброс текущей страницы, сохранение всех без закрытия, валидацию, предпросмотр/отмену темы, ошибку хранилища, повторное открытие/загрузку, активацию проекта, права/пути репозитория, ZIP шаблона и настройку превью чекина. Свежие Qt/QML и Chromium-снимки покрывают восемь страниц при 1400×940 и 900×620. Это сравнение структуры и геометрии, а не доказательство одинаковой растеризации шрифта или выполнения на PostgreSQL/MySQL.

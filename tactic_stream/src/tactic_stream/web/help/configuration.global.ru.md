# Общие предпочтения

> Здесь настраиваются уведомления и диагностика браузера. Применение/сброс относятся только к этой странице, включая черновик DebugSettings.

Уведомления активности и сообщений включают/отключают всплывающие уведомления входящих событий. История, лента и доставка сообщений остаются доступны. Сбор, хранение и автоматическое сохранение диагностики используют существующий DebugSettings; настройки ожидают «Применить». Экспорт и удаление диагностики остаются явными действиями Debug Log.

Значения хранятся в `tactic_stream.preferences.global` и `tactic_stream.debug_log`. При ошибке записи страница восстанавливает предыдущие значения хранилища, оставляет черновик и показывает ошибку. Предпросмотр оформления независим. Трей, локальные потоки, Handler Server и DCC относятся к настольному приложению; запросы браузера обрабатывают штатные серверные процессы из страницы «Сервер».

# Док «Очередь отправки»

Док и окно поверх админки показывают одну общую очередь приложения. Файлы отправляются только по **Отправить всё**, **Отправить текущую**, **Отправить отмеченные** или **Повторить**.

Восстановление панелей не открывает окно очереди и не меняет сохранённую активную панель.
На телефоне восстановленная очередь остаётся внутри своей панели; **Назад к поиску** возвращает результаты.
Закрытие явно открытого окна очереди также возвращает результаты. Ожидающие операции сохраняются.

## Проверка и отправка

Выберите строку для просмотра файлов, объекта, процесса/контекста, описания, превью и назначения. Выделение строки и галка — разные действия: галки управляют отправкой отмеченных и групповыми правками. **Отправить всё** выполняет все готовые операции по порядку. Перемещайте и удаляйте строки; автоматический план версии пересчитывается по оставшимся ожидающим операциям этого контекста.

**Расширенные параметры** содержат репозиторий, версию, имя и файловые опции. Пустая или нулевая версия означает автоматическое назначение. Ревизия сохраняет захваченный нумерованный снапшот и репозиторий; versionless-only не создаёт нумерованную версию. **Сохранить имя источника** отключает обновление latest; **Только versionless** требует его. **Создать превью** использует штатный IconCreator, в том числе выбранную отдельно картинку. Naming preview показывает назначение каждого кадра/тайла и открывает Naming Editor. Просмотр не даёт права записи: чекин проверяет права объекта, snapshot, file и соответствующих полей.

В браузере доступен метод передачи **Upload**. Серверная подготовка использует штатную регистрацию inplace и общий журнал Command/FileUndo. Локальные Copy, Move, In-Place, Preallocate, сохранение DCC и подключение к ТХ недоступны. Repository Sync и S3 исключены.

## Ошибки и восстановление

Отмена загрузки останавливает ожидающую работу; уже отправленная серверная транзакция завершается штатно. Ошибочные/отменённые строки сохраняют файлы для повтора. Потерянный ответ после отправки даёт **Результат неизвестен** и запрещает автоматическое повторение: сначала проверьте Snapshot Browser. Некорректное назначение и чужие пути дают ошибку без незаметной перезаписи. Запоминаемый переключатель **Автоочистка** удаляет успешные строки; ошибки остаются.

Закрытие дока сохраняет очередь. Для восстановления после reload хранятся метаданные операций отдельно для каждого login, без ticket и содержимого файлов. Неотправленные операции возвращаются как **Нужны файлы**; выберите повторно те же относительные пути и размеры. При одинаковых именах в разных каталогах используйте Папка. Закрытие страницы во время исполнения даёт **Результат неизвестен**. Выход предупреждает о потере файловых handles. Завершённая строка открывает свой точный результат в Snapshot Browser.

Подробные controls и превью описаны в [Очереди отправки](commit_queue.ru.md), внутренний путь записи — в [Модели объектов](core_model.ru.md).

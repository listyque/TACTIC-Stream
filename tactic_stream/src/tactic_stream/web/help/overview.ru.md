# Обзор

> TACTIC Stream — браузерное рабочее пространство для объектов проекта, файлов, задач и общения команды. Оно использует ту же бизнес-логику headless TACTIC, что и существующие клиенты.

## Основные элементы

Выберите проект в верхней панели, затем откройте серч-тайп или сохранённый поиск через навигацию. Боковая панель раскрывается поверх рабочего пространства. Компактная полоса переключает открытые разделы; внутри каждого раздела сохраняются отдельные вкладки поиска.

Главная строка поиска — отправная точка для поиска объектов. Фильтры, теги, сортировка и группировка уточняют активную вкладку. Дополнительные операции находятся в компактных меню; нижняя панель управляет страницами, непрерывной загрузкой и созданием объектов.

## Работа с объектом

1. Найдите и выберите объект в активном проекте.
2. Раскройте его процессы и дочерние связи, объявленные в схеме.
3. Откройте задачи, ноутсы, файлы или редактор через действия объекта.
4. Проверьте подготовленную операцию, затем явно сохраните или примените её.
5. Если запрос завершился ошибкой, прочитайте сообщение и журнал отладки перед повторной записью.

## Окна и общение

Конфигурация и админка открываются отдельно от проектной навигации. Рабочие диалоги используют общую шапку: перетаскивание перемещает окно, двойной щелчок или кнопка разворачивания увеличивает его, восстановление возвращает прежние размеры. На маленьком экране используется доступная область браузера.

В сообщениях находятся личные и групповые диалоги. Лента активности показывает события проекта, а системная активность — операции приложения. Это разные разделы.

## Каталог справки

Поиск учитывает названия тем, разделы и полный текст статьи. При отсутствии перевода используется английская статья. Исходный Markdown можно открыть или скачать; после изменения установленных файлов нажмите **Перезагрузить статьи справки**.

Статьи с пометкой **Оригинальная справка ТХ** сохраняют полную документацию соответствующего раздела TACTIC Handler. Desktop-инструкции относятся к ТХ, включая возможности, ещё не перенесённые в браузер. Инструкции для веба адаптируются отдельно и не выдают эти возможности за работающие.

## Общая справка

Каждая кнопка справки открывает одно общее окно с полным каталогом и поиском, выбирая статью текущего экрана или дока. Закрытие справки возвращает к исходному экрану; выделение и несохранённый черновик сохраняются. Документация API открывается отдельно по явно названной ссылке документации API.

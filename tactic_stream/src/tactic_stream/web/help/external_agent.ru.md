# Внешний агент

Откройте проект и страницу, выделите нужные объекты и выберите **Дополнительные
действия → Внешний агент**. Сейчас функция доступна администраторам. Внешний
агент должен быть подключён для того же пользователя и проекта.

Поле контекста показывает, что будет передано: клиент, проект, страница, тип
объектов, табличное представление и ключи выделенных объектов. Опишите нужный
результат. Например: «Создай страницу проверки шотов: код, название и число
кадров, фильтр больше 100 кадров, справа инспектор объекта».

Отметьте **Разрешить запрошенные изменения конфигурации**, чтобы агент мог
сохранить результат. Без этого доступны изучение и предпросмотр. Нажмите
**Отправить агенту** — ниже появятся ход работы и ответ. Созданные страницы и
проекты открываются через обычную навигацию. При необходимости обновите кеш.

Закрытие модального окна не отменяет работу. Откройте его снова или выберите
прежнее обращение в списке. **Новое обращение** захватывает текущую страницу и
выделение. Обращения независимы: в продолжении укажите нужные детали из прошлого
ответа. Отправленная задача сохраняет свой проект, даже если перейти в другой.

**Отменить обращение** отменяет очередь или останавливает подключённого агента.
Уже сохранённые изменения остаются. После обрыва связи проверьте фактический
результат перед новым обращением: прерванные задачи автоматически не повторяются.
Если показано **Внешний агент не подключён**, отправка недоступна. Администратору
нужно подключить внешний процесс агента.

Агент использует штатные инструменты Тактика, права пользователя и проверки
ревизий редакторов. Исполняемые скрипты сохраняются неактивными черновиками.
Проверьте исходник и отчёты в **Редактор скриптов → Черновики агента**, затем
явно активируйте. Хуки и кнопки шелва ТХ исполняются в ТХ; загрузки через браузер
или API не запускают локальные хуки ТХ. Передача контекста не предоставляет
агенту живое управление настольным клиентом.

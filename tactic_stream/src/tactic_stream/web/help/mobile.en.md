# Mobile guide

> The compact workspace shows one active panel and keeps the same account, project and drafts as the desktop layout.

Reducing a desktop window keeps a panel currently displayed there. Hidden panels and inactive dock tabs do not reopen just because the window becomes narrow.

Use navigation to select the project view or an open panel. The search button opens the search field; Result actions contains filters, saved searches and view actions. [Search help](search.en.md) describes the search controls.

The tab button and Open views menu show the current section's coloured circular icon. Each section keeps its own colour and icon; the active section is marked in the menu. Switching search tabs keeps the section identity visible.

The coloured edge of an object card is widest at the left centre and tapers to zero at the upper and lower corners, following the outline without gaps. Its preview fills the left part and progressively blurs and fades towards the right, using the larger web image when available. If the image is missing or fails to load, the initials appear over a fading object accent without changing the card size. The content header remains rectangular.

When a snapshot contains several files, the preview selector shows document icons, names, extensions and sizes. A check marks the displayed file; selecting another row loads that file immediately. Long names are shortened without horizontal scrolling.

[Task Manager](dock.tasks.en.md), [Task Inspector](dock.notes.en.md) and [Task Calendar](dock.task_calendar.en.md) are separate panels. Back returns to the source panel. Additional operations use explicit buttons and menus rather than hover.

Task Manager search opens with a button; Select all tasks is in Task view options. Background updates keep the loaded list and selection in place and leave unchanged results untouched. Task fields omit redundant action buttons; their actions remain in Task actions. Inspector context and Back stay above the notes, with the composer below.

The check-in window has Back in its header and Cancel/Add to Commit Queue pinned at the bottom. Context is optional: leaving it empty uses the selected process. Existing snapshot contexts stay fixed for revisions and attachments. In file preview, the description follows the content and Download/File details stay in the bottom action bar. Routine server success toasts are hidden on phones; errors, warnings and communication notifications remain available.

In [Messages and notes](communication.en.md), Enter inserts a new line; use Send to submit. Drafts remain when changing panels or viewport width. Complex administration and script editing use the desktop layout.

Every Help button opens this shared catalog at the related article. Close Help to return to your previous screen. Use Help topics to show the catalog and search all articles.
